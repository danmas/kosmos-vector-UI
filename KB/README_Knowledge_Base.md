# Раздел Knowledge Base (База знаний)

## Обзор
Knowledge Base — это продвинутый проводник файлов для выбора, какие файлы из проекта должны быть проанализированы и включены в базу знаний. Поддерживает как glob-паттерны, так и ручной выбор файлов.

## Расположение в UI
- **Иконка**: 🗄️
- **Название**: Knowledge Base
- **Позиция**: Второй элемент в левой панели

## Компонент
- **Файл**: `components/FileExplorer.tsx`
- **Размер**: 1186 строк кода
- **Тип**: React функциональный компонент
- **Версия API**: v2.1.1 с обратной совместимостью

## Основные функции

### 1. Выбор папки проекта
- Поле ввода для пути к целевой папке проекта
- Кнопка "Scan Folder" для сканирования структуры
- Поддержка относительных путей (например, `./`)
- Индикация ошибок при недоступных путях

### 2. Режимы выбора файлов

#### Режим по маске (Mask Mode) 🎯
- **Include Mask**: Glob-паттерны для включения файлов
  - Пример: `**/*.{py,js,ts,tsx,go,java}`
  - Поддержка wildcards (`*`, `**`)
- **Ignore Patterns**: Паттерны для исключения
  - Пример: `**/tests/*, **/node_modules/*, **/.git/**`
- Автоматическое применение масок к дереву файлов

#### Режим ручного выбора (Manual Mode) ✋
- Активируется при клике на чекбоксы файлов/папок
- Сохраняет точный список выбранных файлов в `fileSelection`
- Переключается на режим маски при изменении Include Mask

### 3. Дерево файлов (File Tree)

#### Визуализация
- Иерархическое древовидное отображение
- Иконки для папок (▶/▼) и файлов (•)
- Цветовая индикация языков программирования
- Отображение размера файлов в KB
- Счетчики выбранных файлов для папок

#### Интерактивность
- **Клик на чекбокс**: Выбор/снятие выбора файла или папки
- **Клик на имя папки**: Разворачивание/сворачивание
- **Двойной клик на файл**: Открытие файла (текстовые форматы)
- **Иконка просмотра** (👁️): Открывает встроенный просмотрщик

#### Поддерживаемые форматы
Текстовые файлы: js, jsx, ts, tsx, py, go, java, md, txt, json, yaml, yml, xml, html, css, scss, env

### 4. Режимы открытия файлов
Настраивается через `VITE_FILE_OPEN_MODE`:
- **dialog**: Встроенный диалог просмотра (по умолчанию)
- **window**: Новое окно браузера (1200x800)
- **tab**: Новая вкладка браузера

### 5. Custom Settings (Пользовательские настройки)
- Кнопка ⚙️ для открытия диалога настроек
- Произвольное текстовое поле для метаданных
- Сохраняется в `kbConfig.metadata.custom_settings`

### 6. Статистика выбора
- Отображение количества выбранных файлов из общего
- Показ общего размера выбранных файлов в KB
- Индикатор статуса сохранения (💾 Сохранение.../✓ Сохранено!)

## API v2.1.1 Интеграция

### Новые endpoints
1. **GET /api/project/tree** — получение дерева проекта
   - Параметры: `rootPath`, `depth`
   - Возвращает: массив `ProjectFile[]` с языками и размерами

2. **POST /api/project/selection** — сохранение выбора файлов
   - Параметры: `rootPath`, `files: string[]`
   - Обновляет `fileSelection` в KB config

3. **GET /api/kb-config** — получение конфигурации
   - Возвращает: `rootPath`, `includeMask`, `ignorePatterns`, `fileSelection`

4. **POST /api/kb-config** — обновление конфигурации
   - Параметры: частичное обновление `KnowledgeBaseConfig`

### Приоритет режимов (v2.1.1)
1. **fileSelection** (если не пустой) → Ручной режим
2. **includeMask + ignorePatterns** → Режим маски

## Автосохранение
- **Debounce 1 секунда** для изменений путей и масок
- **Немедленное сохранение** при ручном выборе файлов
- Индикатор статуса в правом верхнем углу

## Demo Mode
- При недоступности бэкенда показывает mock-дерево файлов
- Янтарный индикатор "Demo Mode"
- Функционал ограничен просмотром

### Утилиты
- `matchesPattern()` — проверка соответствия glob-паттернам (minimatch)
- `applyMaskToTree()` — применение маски ко всему дереву
- `countSelectedInDirectory()` — подсчет выбранных файлов в папке
- `calculateSelectedSize()` — вычисление общего размера

### Context интеграция
- `currentContextCode` из `DataCacheContext`
- Автоматическая перезагрузка при смене контекста
- Изоляция конфигураций между контекстами

## Диалоги и REST API маршруты

Раздел Knowledge Base вызывает следующие диалоги.

### 1. FileViewerDialog (`components/FileViewerDialog.tsx`)

**Вызов**: Двойной клик по файлу в дереве или иконка 👁️ (просмотр). Режим открытия настраивается через `VITE_FILE_OPEN_MODE` (dialog / window / tab).

**Назначение**: Просмотр содержимого текстовых файлов с подсветкой синтаксиса. Перетаскиваемое и изменяемое модальное окно.

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/api/file-content` | GET | Загрузка содержимого файла. Query: `context-code`, `path` (абсолютный путь к файлу) |

**Пример**: `GET /api/file-content?context-code=CARL&path=src/components/App.tsx`

---

### 2. Custom Settings Modal (inline в FileExplorer)

**Вызов**: Кнопка ⚙️ (Settings) — открывает модальное окно для пользовательских настроек (произвольный текст в `kbConfig.metadata.custom_settings`).

**Назначение**: Ввод метаданных для KB. Не отдельный компонент-диалог, а inline модалка в `FileExplorer.tsx`.

**REST API**: Сохранение через общий flow KB config — см. ниже.

---

### REST API раздела Knowledge Base

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `GET /api/project/tree` | GET | Дерево файлов проекта. Query: `rootPath`, `depth`. Response: `ProjectFile[]` |
| `POST /api/project/selection` | POST | Сохранение выбора файлов. Body: `{ rootPath, files: string[] }` |
| `GET /api/kb-config` | GET | Конфигурация KB: rootPath, includeMask, ignorePatterns, fileSelection |
| `POST /api/kb-config` | POST | Обновление конфигурации (частичное) |
