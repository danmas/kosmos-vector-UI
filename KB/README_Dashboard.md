# Раздел Dashboard (Панель управления)

## Обзор
Dashboard — это главный экран обзора системы AiItem RAG Architect. Предоставляет статистические данные и визуализацию проанализированной кодовой базы.

## Расположение в UI
- **Иконка**: 📊
- **Название**: Dashboard
- **Позиция**: Первый элемент в левой панели

## Компонент
- **Файл**: `components/Dashboard.tsx`
- **Тип**: React функциональный компонент
- **Источник данных**: Использует хук `useDataCache` для доступа к кешированным данным

## Функциональность

### 1. Карточки статистики проекта
Три основные статистические показателя:

#### Total AiItems (Всего элементов)
- Показывает общее количество проанализированных элементов кода (функции, классы, методы и т.д.)
- Отображает процент роста с последнего сканирования
- Цвет: Белый текст

#### Knowledge Links (L1) (Связи знаний)
- Показывает общее количество L1 связей (связи зависимостей)
- Отображает среднюю плотность зависимостей
- Цвет: Синий (#3b82f6)

#### Vector Index Size (Размер векторного индекса)
- Показывает размер векторизованной базы знаний
- Указывает статус оптимизации FAISS индекса
- Цвет: Фиолетовый (#a855f7)

### 2. Графики визуализации

#### Распределение AiItem по типам (Столбчатая диаграмма)
- **Тип**: Горизонтальная столбчатая диаграмма
- **Библиотека**: Recharts
- **Данные**: Количество элементов по типам (function, class, method, module и т.д.)
- **Назначение**: Понимание состава кодовой базы

#### Разбивка по языкам (Круговая диаграмма)
- **Тип**: Круговая диаграмма с процентными метками
- **Библиотека**: Recharts
- **Данные**: Распределение кода по языкам программирования
- **Цвета**: 5 различных цветов для разных языков
  - Синий (#3b82f6)
  - Изумрудный (#10b981)
  - Янтарный (#f59e0b)
  - Фиолетовый (#8b5cf6)
  - Розовый (#ec4899)

### 3. Информация о миграции API
- Отображает информацию о миграции на API v2.1.1
- Показывает новые возможности:
  - Project Tree API с определением размера файлов и языков
  - File Selection API для точного выбора файлов
  - Улучшенная конфигурация KB
  - Обратная совместимость со старыми API

## REST API маршруты

Раздел Dashboard не содержит диалогов. Все данные загружаются через DataCacheContext.

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/api/stats` | GET | Статистика для Dashboard: totalItems, totalDeps, vectorIndexSize, typeStats, languageStats, averageDependencyDensity |

**Context-aware**: Запрос автоматически использует `currentContextCode` (window.g_context_code).

## Поток данных
1. Компонент монтируется и проверяет `currentContextCode` из `DataCacheContext`
2. Загружает статистику через `getStatsWithFallback()` (GET /api/stats)
3. Обновляет состояние полученными данными
4. Отрисовывает статистику и графики
5. Поддерживает Demo Mode при недоступности бэкенда

## Demo Mode (Демо-режим)
- При недоступности бэкенд-сервера отображает мок-статистику
- Показывает янтарный предупреждающий баннер
- Данные не реальные, но позволяют тестировать UI

## Технические детали

### Управление состоянием
```typescript
const [stats, setStats] = useState<DashboardStats | null>(null);
const [isLoading, setIsLoading] = useState(true);
const [error, setError] = useState<string | null>(null);
const [isDemoMode, setIsDemoMode] = useState(false);
```

### Типы данных
- `DashboardStats`: Содержит totalItems, totalDeps, vectorIndexSize, typeStats, languageStats, averageDependencyDensity
- `typeStats`: Массив `{ name: string, count: number }`
- `languageStats`: Массив `{ name: string, value: number }`

## Стилизация
- Фон: slate-900
- Карточки: slate-800 с границами slate-700
- Адаптивная сетка (1 колонка на мобильных, 3 колонки на десктопе для статистики)
- Графики в 2-колоночной сетке на больших экранах

## Поддержка Context Code
- Автоматически обновляется при смене контекстного кода
- Синхронизирует `window.g_context_code` перед API запросами
- Каждый контекст имеет свою собственную статистику
