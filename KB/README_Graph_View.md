# Раздел Graph View (Граф зависимостей)

## Обзор
Graph View — это интерактивная визуализация графа зависимостей кода (L1 уровень). Использует D3.js для создания силового графа с узлами (AiItems) и рёбрами (связи между ними). Поддерживает расширенную фильтрацию и навигацию.

## Расположение в UI
- **Иконка**: 🕸️
- **Название**: Graph View
- **Позиция**: Пятый элемент в левой панели

## Компонент
- **Файл**: `components/KnowledgeGraph.tsx`
- **Размер**: 1304 строки кода
- **Библиотека**: D3.js v7.9.0
- **Тип**: React функциональный компонент

## Визуализация графа

### Узлы (Nodes)

#### Формы узлов по типам
- **Круги** — Function, Class, Method, Module, Interface, Struct
- **Квадраты** — Table (базы данных)
- **Прямоугольники** (1:3) — Table_Column

#### Цвета узлов
- Function: #3b82f6 (синий)
- Class: #10b981 (изумрудный)
- Method: #a855f7 (фиолетовый)
- Module: #14b8a6 (бирюзовый)
- Struct: #f59e0b (янтарный, Go)
- Interface: #ec4899 (розовый)
- Table: #06b6d4 (голубой)
- Table_Column: #6366f1 (индиго)

#### Размер узлов
- Круги: радиус 20px
- Квадраты: 40x40px
- Прямоугольники: 40x13px

#### Метки узлов
- Текст справа от узла (+25px по X, +5px по Y)
- Показывает последнюю часть ID (после последней точки)
- Тень текста для читаемости: `2px 2px 4px #000`
- Цвет: #cbd5e1 (светло-серый)

### Рёбра (Links/Edges)

#### Типы связей
Реальные типы с бэкенда:
- `calls` — вызовы функций
- `imports` — импорты модулей
- `reads_from` — чтение данных
- `updates` — обновление данных
- `extends` — наследование
- `implements` — реализация интерфейса

#### Визуализация связей

- **Стрелки**: Маркеры на конце (8x8px)

- **Позиция метки**: Середина линии

## Интерактивность

### Управление мышью

#### Колесо мыши (Zoom)
- **Прокрутка вверх**: Приближение (zoom in)
- **Прокрутка вниз**: Отдаление (zoom out)
- **Чувствительность**: 0.15 (увеличена в 1.5 раза от стандарта)
- **Диапазон**: 0.1x - 4x
- **Без Ctrl**: Работает напрямую

#### Панорамирование (Pan)
- **ЛКМ по фону**: Перетаскивание всего графа
- **Плавная анимация**: 50ms transition
- **Курсор**: `move` на пустом пространстве

#### Двойной клик по фону
- **Действие**: Сброс фокуса на узлах
- **Результат**: Показывает все узлы без выделения

### Взаимодействие с узлами

#### Одиночный клик
- **Добавление в историю** (max 5 кликов)
- **Добавление в session history** (без ограничений)
- **Подсветка жёлтым** обводка

#### Двойной клик
- **Без Ctrl**: Фокус ТОЛЬКО на этом узле + соседи
- **Повторный дабл-клик**: Снимает фокус

#### Ctrl + клик
- **Действие**: Добавление связанных узлов к текущему фильтру
- **Логика**: Аддитивная (расширение видимости)
- **Поиск связей**: Из ПОЛНОГО графа (не из отфильтрованного)
- **Обновление**: Обновляет `filteredItemIds` в контексте

#### Alt + клик
- **Действие**: ИЗОЛЯЦИЯ — показать ТОЛЬКО этот узел + соседи
- **Сброс фильтров**: Очищает поиск и другие фильтры
- **Установка фокуса**: Только на выбранном узле

#### Перетаскивание (Drag)
- **Drag start**: Симуляция возобновляется (alphaTarget 0.3)
- **Drag**: Узел фиксируется в новой позиции
- **Drag end**: Симуляция замедляется, узел освобождается
- **Предотвращение**: Не активирует панорамирование

### Persistent Tooltip (Всплывающая подсказка)

#### Активация
- **Наведение мыши** + **удержание 1000ms** (настраивается)
- **Позиция**: Рядом с курсором (+20px X, -10px Y)
- **Остаётся**: До явного закрытия (крестик)

#### Содержимое
- **ID элемента**
- **Тип** (с цветным бейджем)
- **Язык**
- **L2 описание** (если есть)
- **Кнопка "Details"**: Открывает модальное окно
- **Кнопка закрытия** (×)

#### Визуальное выделение узла
При появлении tooltip узел получает выделение:
- **Цвет обводки**: #22c55e (ярко-зелёный)
- **Толщина обводки**: 4px
- **Действие**: Выделяет узел, для которого показан tooltip
- **Сохранение**: При клике на кнопки в tooltip (Details, закрытие) обводка сохраняется
- **Снятие**: При клике на другой узел или при открытии tooltip для другого узла

### Модальное окно деталей узла

#### Открытие
- **Кнопка "Details"** в tooltip
- **Загрузка**: Полные данные через `apiClient.getItem(id)`

#### Содержимое
Аналогично Data Inspector:
- **Заголовок**: ID + тип + кнопки (T, V)
- **Теги элемента**
- **Вкладки**: L0, L1, L2
- **Те же компоненты**: `L0SourceView`, `L1ConnectivityView`, `L2SemanticsView`

#### Векторизация в модальном окне
- **Кнопка "V"**: Векторизация элемента
- **Индикатор**: Меняет цвет после векторизации
- **Force mode**: Всегда перезаписывает

#### Управление тегами
- **Кнопка "T"**: Открывает `TagsDialog`
- **Автообновление**: Перезагружает теги после закрытия диалога

## Поиск и фильтрация

### Поле поиска графа

#### Синтаксис
- **Простой текст**: Подстрока в ID узла
- **Regex**: `/pattern/flags` — полный regex
- **Wildcards**:
  - `*` — любое количество символов
  - `~X` — любой символ кроме X
  - `~[sequence]` — исключение последовательности
  - `^`, `$`, `|` — якоря и альтернативы

#### Примеры
- `^carl_.*|auth_.*` — узлы начинающиеся с carl_ или auth_
- `*Service*` — все сервисы
- `user~[Admin]` — user но не userAdmin

#### История поиска
- **Выпадающий список** с последними запросами
- **Кнопка "Clear"** для очистки истории
- **Auto-close**: При клике вне списка или Escape

### Фильтр из Inspector
- **Синхронизация**: Через `inspectorSearch` из контекста
- **Приоритет**: Поиск графа > поиск инспектора > фильтры > показать всё
- **Автообновление**: Graph реагирует на изменения в Inspector

### Filter Dialog
- **Фильтр по типам**: Checkbox-список типов AiItems
- **Фильтр по тегам**: Checkbox-список тегов
- **Кнопка активации**: В правом верхнем углу
- **Индикатор**: Меняет цвет при активных фильтрах

## Физическая симуляция (D3 Force)

### Силы
- **forceLink**: Связи притягивают узлы (distance=150)
- **forceManyBody**: Узлы отталкиваются (strength=-400)
  - **Barnes-Hut оптимизация**: theta=0.9 (O(n log n))
  - **distanceMax**: 300px (игнорировать дальние узлы)
- **forceCenter**: Центрирование графа
- **forceCollide**: Предотвращение перекрытий (radius=40)

### Параметры симуляции
- **alphaDecay**: 0.05 (быстрое затухание)
- **alphaMin**: 0.001 (ранняя остановка)
- **Прогрев**: 50 тиков без отрисовки перед показом

### Производительность
- **Логирование**: Время создания, тики, стабилизация
- **Оптимизация**: Batch DOM updates в tick callback
- **Debounce**: 300ms для применения фильтров

## Кэширование и загрузка

### DataCacheContext
- **Первый запрос**: Проверка кэша
- **Cache hit**: Мгновенная отрисовка (логирование времени)
- **Cache miss**: Загрузка с сервера → сохранение в кэш
- **Индикатор**: "Cached" бейдж (зелёный)

### Граф данных

## Диалоги и REST API маршруты

Раздел Graph View вызывает следующие диалоги. Каждый диалог связан с определёнными REST API endpoints.

### 1. NaturalQueryDialog (`components/NaturalQueryDialog.tsx`)

**Вызов**: Кнопка "Query" в панели поиска графа.

**Назначение**: Поиск элементов по запросу на естественном языке. LLM преобразует вопрос в regex или фильтр, результат применяется к полю поиска графа.

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/api/agent-scripts` | GET | Список сохранённых скриптов-запросов (пагинация: page, limit) |
| `/api/agent-scripts/:id` | GET | Детали скрипта по ID |
| `/api/v1/natural-query` | POST | Основной запрос: `{ question }` → результат + scriptId |
| `/api/v1/natural-query/suggest` | GET | Поиск похожих вопросов: `?query=...` |
| `/api/agent-scripts/:id` | PUT | Обновление скрипта (код, is_valid) |
| `/api/agent-scripts/:id/execute` | POST | Выполнение сохранённого скрипта |

**Связь с UI**: Результат (`onApplyResult`) устанавливается в `graphSearch` через `setGraphSearch`.

---

### 2. TagsDialog (`components/TagsDialog.tsx`)

**Вызов**: Кнопка "T" в модальном окне деталей узла (после клика на узел → Details).

**Назначение**: Управление тегами выбранного AI Item (добавление/удаление, создание новых тегов).

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/api/tags` | GET | Список всех доступных тегов |
| `/api/items/:id/tags` | GET | Теги конкретного AI Item |
| `/api/items/:id/tags` | PUT | Синхронизация тегов (замена всего списка): `{ tagCodes: string[] }` |
| `POST /api/ai-items/bulk/tags/add` | POST | Массовое добавление тегов (если bulkMode='add') |
| `POST /api/ai-items/bulk/tags/remove` | POST | Массовое удаление тегов (если bulkMode='remove') |
| `POST /api/tags` | POST | Создание нового тега: `{ code, name, description }` |

---

### 3. FilterDialog (`components/FilterDialog.tsx`)

**Вызов**: Кнопка "Filter" в правом верхнем углу панели графа.

**Назначение**: Фильтрация узлов графа по типам и тегам. Общий контекст `GraphFilterContext` синхронизирует фильтры с Data Inspector.

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/api/types` | GET | Список типов AI Items (для checkbox-фильтра) |
| `/api/tags` | GET | Список тегов (для checkbox-фильтра) |

---

### 4. Модальное окно деталей узла (встроенное в `KnowledgeGraph.tsx`)

**Вызов**: Кнопка "Details" в tooltip при наведении на узел, или двойной клик по узлу.

**Назначение**: Просмотр L0/L1/L2, векторизация, управление тегами. Не отдельный диалог-компонент, а inline-модалка.

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/api/graph` | GET | Загрузка графа (nodes, links), context-aware |
| `/api/items/:id` | GET | Полные данные AI Item при открытии деталей |
| `/api/items/:id/tags` | GET | Теги элемента (для отображения и TagsDialog) |
| `/vectorize-ai-items` | POST | Векторизация: `{ fullNames: string[], force: boolean }` |

## Session History (Полная история)
