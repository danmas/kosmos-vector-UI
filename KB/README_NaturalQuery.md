# Natural Query Engine — Запросы на естественном языке

**Назначение:** Интеллектуальный слой анализа кодовой базы, преобразующий вопросы на естественном языке в исполняемый код и структурированные данные.

---

## 1. Как это работает (Конвейер запроса)

Процесс обработки вопроса проходит через несколько стадий:

1.  **Поиск в кэше (FTS):**
    *   Система выполняет полнотекстовый поиск в таблице `agent_script`.
    *   Если найден похожий валидный вопрос (`is_valid = true`), используется существующий JS-скрипт. Это значительно ускоряет ответ.

2.  **Генерация скрипта (LLM):**
    *   Если кэш пуст, вопрос отправляется в LLM (Gemini/Claude) с системным промптом.
    *   Промпт содержит схему БД (`ai_item`, `link`), типы связей (`calls`, `reads_from`) и примеры кода.
    *   LLM возвращает асинхронную функцию `execute(contextCode)`.

3.  **Выполнение в Sandbox:**
    *   Скрипт выполняется в изолированной среде (`new Function`).
    *   **Безопасность:** Доступен только `safeDbService`, который разрешает исключительно `SELECT`-запросы.
    *   **Таймаут:** Ограничение времени выполнения (обычно 5 секунд).

4.  **«Гуманизация» (Humanize):**
    *   Результаты из БД вместе с исходным вопросом отправляются в LLM для формулирования ответа на человеческом языке.

---

## 2. Интерфейс Natural Query

Диалоговое окно (виджет) предоставляет три уровня представления данных:

*   **Interpretation (Интерпретация):** Текстовый ответ на вопрос (например: «В проекте найдено 12 SQL-функций, работающих с таблицей пользователей»).
*   **Agent Script (Скрипт агента):** Просмотр сгенерированного JS-кода с подсветкой синтаксиса. Здесь можно отредактировать код и запустить его вручную (кнопка *Run*).
*   **Raw Data (Сырые данные):** Результат выполнения SQL-запроса в формате JSON.

---

## 3. Интеграция с Knowledge Graph

Одной из ключевых функций является кнопка **"Apply to Filter"**:
*   Она извлекает идентификаторы (имена функций, пути файлов) из результатов запроса.
*   Генерирует оптимизированное регулярное выражение (например, `/^(login|getUser|updateProfile)$/i`).
*   Применяет это выражение к фильтру графа, мгновенно подсвечивая целевые узлы на графе зависимостей.

---

## 4. Безопасность и надежность

*   **Только чтение:** Скрипты не могут изменять данные в базе.
*   **Изоляция:** Скрипты не имеют доступа к файловой системе сервера или сетевым запросам (кроме разрешенного API).
*   **Авто-инвалидация:** Если скрипт вызвал ошибку при исполнении, он помечается как `is_valid = false` и не предлагается другим пользователям через кэш.
